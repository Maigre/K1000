# CLAUDE.md — K1000 workspace

K1000 is Thomas's portable live DSP head for his mobile sound rig (Meyer USW subs + UPA-1P tops,
all self-powered). This repo is the **project workspace**: requirements, reviews, decisions,
roadmap and progress live here as Markdown before (and beside) any code.

- Hub slug: `k1000` (37Projects). Commit trailer for task work: `Refs-37: k1000#t-NNN [done]`.
- Read first: `README.md` → `docs/requirements.md` → `DECISIONS.md` → `ROADMAP.md`.
- **Decisions** are recorded in `DECISIONS.md` (one entry per decision: context, options, choice,
  why). A decision is only "decided" once Thomas says so — proposals stay `proposed`.
- Reviews and studies go to `docs/NN-<topic>.md`, numbered in creation order, never rewritten
  after a decision cites them (add a follow-up doc instead).
- Public repo: no secrets, no client names, no private network details.
- Language: English for docs and code.
