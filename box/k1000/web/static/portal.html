It cannot check the K1000 certificate, and it is not where K1000 runs.

  1. Tap ⋮ (top right) › Use this network as is.
  2. Open Chrome and go to http://10.42.0.1/ (this page): it then says whether the certificate is installed, and Open K1000 works.
  3. Once K1000 is installed: just tap its icon.

First time on this phone

  1. The phone needs a screen lock (PIN, pattern…): Android refuses certificates without one.
  2. Download the K1000 certificate Chrome may say the file "can't be downloaded securely": tap Keep.
  3. Do NOT open the downloaded file (Android 11+ says "Can't install CA certificates" when you do). Instead: Settings › Security & privacy › More security settings › Encryption & credentials › Install a certificate › CA certificate › Install anyway › pick k1000-ca.crt.
  4. Come back here and reload: it should say trusts the K1000 certificate ✓. Then Open K1000, and Install (or Chrome ⋮ › Add to Home screen).

This certificate can only vouch for the K1000 box (10.42.0.x and k1000.home.arpa), never for another site. Android then shows "Network may be monitored": expected, harmless here.

At a gig: airplane mode, then Wi-Fi on, then the K1000 icon.
